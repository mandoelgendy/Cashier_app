
# 🍔 نظام كاشير المطاعم المحترف | Restaurant POS System

تطبيق سطح مكتب لإدارة مبيعات وفواتير المطاعم واحتساب الضرائب، مبني بلغة بايثون باستخدام الواجهة الرسومية **Tkinter**.

## ✨ الميزات الرئيسية
- 📂 تقسيم الأصناف والمأكولات إلى تبويبات منظمة.
- 🧮 احتساب تلقائي للإجمالي والضريبة (14%).
- 📑 توليد فواتير فريدة لكل طلب وحفظها بصيغة تكست `txt`.
- 🔄 ميزة تفريغ السلة وبدء طلب جديد كلياً برقم فاتورة عشوائي.

## 🛠️ طريقة التشغيل
1. تأكد من تثبيت لغة [Python](https://python.org).
2. قم بتحميل المشروع أو عمل Clone له:
   ```bash
   git clone https://github.com
   ```
3. افتح المجلد وشغل الملف الأساسي:
   ```bash
   python main.py
   ```
